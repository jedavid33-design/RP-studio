Version 1.2.0 adds (reliability + safety fixes from the 2026-10-01 audit):
- Corrupt saved data can no longer white-screen the app. Every saved-data read
  at startup is guarded; on corruption the app boots into a recovery banner
  with Export still reachable, and the damaged copy is preserved in the
  browser's storage under a "corrupt" backup key instead of being overwritten.
- A real in-flight turn lock: the keyboard shortcut, Send, Retry, Hands-off,
  Continuity, Refresh memory, and both repair buttons are all locked while a
  turn is generating, so concurrent generations can no longer interleave the
  transcript or burn extra API calls.
- Cloud sync no longer silently drops edits saved during an upload: the push
  stamps from a pre-upload snapshot and automatically re-pushes anything saved
  mid-flight.
- Trash: deleting a story, clearing a session, or removing a profile now moves
  it to a Trash section (Restore / Delete forever) instead of destroying it
  immediately. Trash syncs between devices.
- Storage-full no longer kills the app silently: failed saves show a persistent
  banner with an Export button, and the app keeps working.
- Sync conflicts: after declining the cloud copy you are now offered an
  explicit "upload my copy as the newest version" choice instead of a dead end.
- Connecting a sync code now downloads a dated safety backup of the local
  library before replacing it.
- "Duplicate current" now truly duplicates the story, transcript included.
- A blocked reply can no longer leak into a different story after switching.
- Empty cloud copies are rejected with a clean error instead of crashing sync.
- Empty model replies are treated as errors (nothing saved) instead of blank
  story cards.
- "Use as player" now asks for confirmation, and character profiles can be
  edited (not just deleted and recreated).
- A visible warning when the 12-guardrail cap drops the oldest lesson, and a
  note in Settings that the Worker URL and app password are stored as plain
  text in the browser.

Version 1.1.4 added:
- A chronology/no-replay firewall. Completed calls, scenes, dialogue, and events
  stay in the past; continuity memory is reference material, not prose to repeat.
- Memory refresh and Continuity Repair now explicitly preserve forward chronology
  and replace repeated material from the last valid point.
- A natural handoff. If continuing would require controlling the player, the AI
  can stop cleanly and display “Continue as [player]—or move the scene forward.”
- NPC-initiated contact such as a hand on Jace's shoulder no longer triggers a
  false Agency Shield block unless the reply also invents Jace's reaction.
- Agency Shield now displays the exact matched phrase instead of the surrounding
  paragraph.
- Learned guardrails can be reviewed and removed from Edit story.

Version 1.1.3 added:
- An NPC Knowledge Firewall that prevents private player notes, thoughts, medical
  details, and setup information from silently becoming NPC knowledge.
- A Continuity error button that replaces a contradictory reply from the last
  valid turn and explicitly forbids the model from rationalizing its mistake.
- Optional user-written correction notes. RP Studio remembers up to twelve
  story-specific guardrails and includes them in future turns on every device.
- Agency Shield now shows the exact caught phrase, recognizes more imposed
  reactions, tolerates exact callbacks to the player's latest established move,
  and lets you edit a blocked reply for free.

Version 1.1.2 added:
- A stronger POV firewall that freezes the player character at the end of each
  user turn, even when the user's own prose is written in second person.
- All turn and repair instructions now stay in the leading system prompt. This
  prevents RP models from echoing a trailing NEXT NPC TURN instruction.
- Expanded Agency Shield checks for player perceptions and footsteps, plus
  cleanup for any leaked instruction header.

Version 1.1.1 added:
- A new edge-to-edge opal-glass icon with a translucent milky book-and-quill
  symbol. The folder includes a 1024px master plus the PWA and Apple-touch sizes.
- An Add OpenRouter credits button when OpenRouter returns an insufficient-credit,
  payment-required, or paid-account-upgrade error. Other provider errors remain
  plain error messages.

Version 1.1.0 included:
- A quote-aware Agency Shield correction. NPC dialogue may accuse, question, or
  speculate about the player without triggering a false positive. Identity
  clauses such as "He knows who Jace is" are no longer mistaken for narration
  of Jace's state. Player-attributed dialogue and genuine player takeover remain
  blocked.
- Optional encrypted cloud sync for stories, full transcripts, continuity
  memory, profiles, and model preferences.
- Automatic background uploads after changes, manual Sync now, conflict
  protection, and continued offline/local saving.

Cloud sync also requires the separate RP-Studio-Worker-v1.1.0 update and an RP_DB
D1 binding. Install the Worker update first. Existing local stories, connection
settings, and manual backup/import remain intact when installing this website ZIP.
