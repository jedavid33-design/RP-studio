RP Studio v1.0.5.2

Upload all seven files in this ZIP to the root of your RP-studio GitHub repository:
index.html, style.css, app.js, manifest.webmanifest, apple-touch-icon.png,
icon-192.png, and icon-512.png.
Choose Replace when GitHub warns that files with those names already exist.

This update does not erase your saved story, settings, Worker URL, app password,
or conversation. The new Hands off Olivia button rejects the latest AI reply and
regenerates it with an explicit player-agency correction.

Version 1.0.3 also removes exposed AI planning/reasoning and displays only the
finished story prose.

Version 1.0.4 added manual continuity memory. Refresh memory compresses older
turns for the model while keeping the complete transcript visible and saved.
It also strengthens the automatic player-agency guard, adds the neon quill-and-book
Home Screen icon, and changes the interface to a lighter opal theme.

Version 1.0.5 adds a story library, reusable character profiles, portable JSON
backup/import, and a memory meter that recommends when to refresh without spending
credits automatically. Existing v1.0.4 browser data migrates into the first story.

Version 1.0.5.1 adds true paragraph spacing, strips incomplete story tags, and
automatically requests one corrected rewrite when the local agency shield detects
second-person narration outside NPC dialogue. The extra request happens only when
the first reply fails the agency check.

Version 1.0.5.2 expands the agency shield to catch third-person player takeover.
The player's first name or surname outside quoted NPC dialogue now triggers the same
automatic correction, and the prompt forbids player-referencing pronouns in narration.

After GitHub Pages finishes deploying, fully close and reopen RP Studio.
